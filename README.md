# Business Data Extraction & Analytics Dashboard

# Project Overview
This project demonstrates a low-code workflow for extracting, validating, cleaning, storing, and visualizing structured book data.

# Tools Used
- Apify
- n8n Cloud
- Google Sheets
- Looker Studio

# Workflow
1. Extract book information using Apify.
2. Process and validate records in n8n.
3. Clean fields such as price and rating.
4. Store structured records in Google Sheets.
5. Analyze book prices, ratings, genres, and availability in Looker Studio.

# Key Features
- Automated data extraction workflow
- Data validation and cleaning
- Structured data storage
- Interactive dashboard and filters
